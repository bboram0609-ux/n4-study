# N4 스터디

JLPT N4 대비 학습 웹앱(PWA)입니다. 설치 없이 브라우저에서 바로 쓸 수 있고, 휴대폰 홈 화면에 추가하면 앱처럼 오프라인으로도 동작합니다.

## 기능

- **단어 플래시카드** — N4 단어 254개 (명사·동사·형용사·부사), 품사별 필터, 목록·검색
- **한자** — N4 한자 121자, 음독·훈독·뜻·예시 단어, 카드 학습과 한자표
- **문법** — N4 핵심 문형 43개, 접속 방법과 예문(한국어 해석), 학습 완료 체크
- **모의 퀴즈** — 단어 뜻 / 단어 읽기 / 한자 뜻 / 문법 빈칸 / 종합, 10·20·30문제, 기록 저장
- **간격 반복 복습** — '다시 / 애매해요 / 알아요'에 따라 1·3·7·14·30·60일 간격으로 다시 출제, 퀴즈에서 틀린 단어도 자동 추가
- **일본어 발음 듣기** (🔊, 브라우저 음성 합성) · 연속 학습일 · 다크 모드

학습 기록은 각자 기기의 브라우저(localStorage)에 저장됩니다.

## 실행

빌드 과정이 없는 정적 사이트입니다.

```bash
python3 -m http.server 8000
# http://localhost:8000 접속
```

## 배포 (GitHub Pages)

저장소 **Settings → Pages**에서 Source를 `Deploy from a branch`, 브랜치 `main` / `/ (root)`로 지정하면
`https://<사용자명>.github.io/n4-study/` 주소로 접속할 수 있습니다.
휴대폰에서 접속한 뒤 "홈 화면에 추가"를 누르면 앱처럼 설치됩니다.

## 구조

```
index.html            앱 화면 틀
styles.css            스타일 (라이트/다크)
app.js                화면·플래시카드·간격 반복·퀴즈 로직
data/vocab.js         단어 데이터
data/kanji.js         한자 데이터
data/grammar.js       문법·예문·퀴즈 데이터
sw.js                 오프라인 캐시 (서비스 워커)
manifest.webmanifest  PWA 설정
icons/                앱 아이콘
```

단어·한자·문법을 추가하려면 `data/` 안의 파일에 같은 형식으로 항목을 넣으면 됩니다.
파일을 수정해 배포할 때는 `sw.js`의 `CACHE` 버전(`n4-study-v1`)을 올려야 사용자 기기에서 새 버전으로 갱신됩니다.
